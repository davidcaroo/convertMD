El Conversor Universal de Documentos a Markdown para IA

Transforma Word, Excel, PowerPoint, PDF, CSV, JSON e imágenes con OCR en formato Markdown limpio, estructurado y optimizado para LLMs y sistemas RAG. Aplicación nativa y portable para Windows.

Diseñado para la Ingesta de Datos en IA

Convierte documentos complejos en texto estructurado puro, eliminando el ruido que confunde a los modelos de lenguaje y reduce la efectividad de tus prompts.

Motor Microsoft MarkItDown Oficial

Aprovecha el motor de ingeniería desarrollado por Microsoft para extraer la estructura semántica original de hojas de cálculo, diapositivas y documentos sin perder celdas ni relaciones.

100% Offline & Privacidad Total

Tus documentos confidenciales, estados contables y contratos nunca se transmiten por internet ni tocan servidores externos. Todo el cómputo se realiza de forma estrictamente local.

Optimizado para RAG & Agentes LLM

Genera Markdown GitHub Flavored (GFM) impecable, con tablas delimitadas por tuberías, títulos jerárquicos y bloques de código listos para su indexación en bases de datos vectoriales.

Flujo de Conversión en Tres Pasos

Un flujo de trabajo directo, veloz y sin configuraciones complicadas. De cualquier formato a Markdown en milisegundos.

01

Arrastra o Selecciona

Arrastra cualquier archivo compatible a la zona de carga de ConvertMD o selecciónalo directamente con el explorador nativo de Windows.

02

Extracción Multihilo & OCR

El motor procesa el archivo en un hilo asíncrono secundario para mantener la interfaz 100% responsiva, aplicando OCR nativo de Windows si se trata de una imagen.

03

Previsualiza y Exporta

Inspecciona el resultado con contador de líneas, palabras y caracteres en tiempo real. Guarda el archivo `.md` con un clic o cópialo de inmediato al portapapeles.

Código Abierto y Ejecución Local

ConvertMD es 100% Open Source. Puedes auditar el código, clonarlo, personalizarlo o compilar tus propios ejecutables.

powershell / bash
$ git clone https://github.com/davidcaroo/convertMD.git
$ cd convertMD
# Instalar dependencias oficiales de Microsoft MarkItDown y CustomTkinter
$ pip install -r requirements.txt
# Iniciar la aplicación nativa
$ python main.py
# Para recompilar el portable y el instalador:
$ python build_release.py
